# SaaS Admin Dashboard

A modern, responsive analytics dashboard built with **React**, **Vite**, **TailwindCSS**, and **Recharts**. Designed to demonstrate capability in building enterprise-grade user interfaces.

## Features
*   **Responsive Layout:** Sidebar navigation that adapts to screen size.
*   **Data Visualization:** Interactive charts using Recharts.
*   **Modern Styling:** Clean, professional aesthetic using TailwindCSS utility classes.
*   **Component Architecture:** Reusable components for stats cards and list items.

## Tech Stack
*   React 18
*   Vite
*   TailwindCSS
*   Recharts
*   Lucide React (Icons)

## Setup

1.  **Install Dependencies:**
    ```bash
    npm install
    ```

2.  **Start Development Server:**
    ```bash
    npm run dev
    ```

3.  **Build for Production:**
    ```bash
    npm run build
    ```
